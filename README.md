# Spin It!

A simple random choice wheel built with HTML, CSS, and JavaScript.

## Features

- Add and remove choices
- Supports 3–12 wheel options
- Random animated wheel spin
- Responsive layout
- Winner display and particle animation

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API

## About

Spin It! is a free browser-based tool for making quick random decisions.
